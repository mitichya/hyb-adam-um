This repository contains the code, data-processing scripts, and result files
corresponding to the revised manuscript:

**Hyb-Adam-UM: hybrid ultrametric-aware mtDNA phylogeny reconstruction**

The current version uses MAFFT-derived pairwise-deletion p-distance matrices
and ML reference trees inferred from the full MAFFT alignments using IQ-TREE.
These files correspond to the revised benchmark reported in the manuscript.

The folder `archive_old_NW_version/` contains an earlier prototype based on
pairwise Needleman--Wunsch distances. That prototype is retained only for
transparency and is not used for the revised manuscript results.
